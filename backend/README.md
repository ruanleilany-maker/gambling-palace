# Backend de Gambling Palace (pendiente)

Carpeta reservada para la API privada Node.js + Express.
Aún no existe autenticación, base de datos ni endpoint funcional.

En las siguientes etapas se añadirán:
- Validación de sesiones y permisos (estudiante / administrador).
- Catálogo de juegos y lecciones con operaciones CRUD.
- Registro de intentos y resultados educativos.
- Formulario de contacto real.
- Integración de Palace AI, con clave exclusivamente en servidor.

Nunca publicar credenciales, contraseñas ni claves de API en este repositorio.
